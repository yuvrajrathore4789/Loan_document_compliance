# Sample documents

All files here are **synthetic** (generated by `scripts/generate_demo_data.py`, fictional names/identifiers, masked Aadhaar, GSTIN-valid fictional numbers). They are layouts invented for this demo, not copies of any official document.

| Folder | What it demonstrates |
|---|---|
| `clean/` | A salaried applicant whose documents agree with each other |
| `name_mismatch/` | Aadhaar carries a materially different surname (R002) |
| `low_ocr/` | PAN and Aadhaar as degraded scans (R008 plus extraction problems) |
| `anomalous_large_credit/` | One unusually large credit in the bank statement (R014) |
| `prompt_injection/` | Application form containing instruction-like text, flagged for manual review (R016) |
| `corrupted_pdf/` | Truncated Aadhaar PDF, reported as a processing exception (R010), not as fraud |

Upload a folder's files to a new application whose applicant name matches the document holder (the name is printed on each document), then run verification.
